## How to read

Each brief includes:
- Portfolio snapshot and current exposure
- AI-infra value-chain map (what you own vs. what's missing)
- Ranked candidates per missing layer, with catalyst + primary risk
- Macro regime check (qualitative, applying `macro-regime-detector` logic)
- Position-sizing suggestion grounded in the Druckenmiller conviction table
- What to monitor (specific trip-wires that would change the thesis)

## Disclaimer

None of these briefs are financial advice. They apply the repo's heuristic frameworks to public information; verify every claim against live data (13F filings via `institutional-flow-tracker`, theme heat via `theme-detector`) before acting.
